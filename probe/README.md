# 观势桌面采集探针

内部版本0.1.0，提供Windows x64及macOS Intel/Apple Silicon包。探针主动连接远端平台，使用这台电脑的系统Google Chrome登录和采集，无需端口、隧道或服务器反连。

## 安装和首次使用

1. 打开平台 [采集设备](http://10.255.200.16:18080/devices)，下载对应系统包。Mac在“关于本机”查看Intel或Apple芯片。
2. Windows运行`.exe`安装到当前用户；Mac解压ZIP，将“观势采集探针.app”拖到“应用程序”并启动。电脑需已安装Google Chrome。
3. 用户已接受未签名内部分发。系统提示未知发布者时，按系统提供的“更多信息/仍要运行”或macOS“隐私与安全/仍要打开”完成这一个应用的确认；不关闭全局防护。公司策略阻止时保留错误信息交管理员处理。本版尚未原生验收。
4. Web生成一次性配对配置，复制到探针。地址自动填入`https://10.255.200.16:18443`；填写设备备注、勾选业务采集授权并配对。配置十分钟有效、单次使用，过期重新生成，不交给无关设备。
5. 已连接后，在Web“数据源”账号行选择这台设备的采集浏览器，点击“在设备Chrome登录”。也可从探针选择平台、填账号备注并打开Chrome，平台创建绑定该设备的登录记录。
6. 在真实Chrome扫码/输入/处理验证码，再点击“我已完成登录”。表示资料保留在本机，首次采集还要核对是否可用，不凭按钮认定网站可采。
7. Web将账号绑定到真实公司招聘或舆情来源，按已有任务/计划执行，保持电脑、探针与Chrome在线。

公开CA随配对配置传入探针，正常验证HTTPS/WSS，无需手工导入系统根证书。Web HTTPS入口首次可能显示内部证书提示；原HTTP入口保留。管理员须保证配置来自自己的平台。

## 日常操作

- 关闭窗口后托盘常驻，可显示/暂停/退出。勾选“登录电脑后自动启动探针”使用用户级启动。
- 不同平台可共享专用Chrome资料；同平台不同账号使用Web新增的独立浏览器资料，不复制日常Chrome登录。
- 电脑离线/睡眠、Chrome关闭或账号受限时查看任务原因；已有岗位不因设备离线被判下架，结果未知的操作不自动重复。
- 解除配对请求平台撤销身份，保留Chrome资料；网络失败可先在Web撤销。暂停阻止继续接收采集，退出断开连接。
- Windows卸载使用系统“已安装的应用”；Mac退出后移走`.app`。身份/浏览器资料与程序分开保存，卸载不自动清除资料。弃用设备先在Web撤销，需要删除资料时交管理员按明确设备目录处理。
- 首版更新由管理员发布新包，退出后安装/替换同一应用；没有后台自动更新，原生升级保留身份/资料尚未验收。

## 工程说明

Electron/TypeScript，package-lock固定版本。`npm ci`、`npm test`、`npm run package:win`/`package:mac`仅在合适的授权构建环境执行；当前用户电脑禁止重建开发环境或运行测试。实施证据见 [记录](../docs/PROBE_IMPLEMENTATION.md)。

凭据/命令日志通过系统秘密存储加密。仅有界浏览器操作，不执行服务端Shell、任意脚本或Agent候选代码。配对配置、设备身份、Chrome资料、安装包/工具缓存不入Git。
