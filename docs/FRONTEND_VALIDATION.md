## 实际发现并修复

1. 窄屏表格字段被压成逐字换行：增加表格最小宽度与横向滚动，标题操作区允许换行；导航保留滚动。
2. 窄屏图标导航无可访问名称：NavLink增加aria-label与title。
3. React19与Ant Design5兼容告警：读取官方npm包元数据/README后，固定加入`@ant-design/v5-patch-for-react-19@1.0.3`并在入口导入。重载后实际打开/取消配置弹窗，本轮error日志为空；详细决策见DEC-0019。
4. 远程总览截图发现非招聘任务名称为空：统一从公司名、舆情关注对象或任务名称取标题，并按任务类型展示说明。重新构建后由远端复验，不重跑已完成业务任务。
